# Hokkaido, Where the Stations Were（駅のあった北海道）1950–2025

\#30DayMapChallenge 2026 Day 1「Points」の作品。

北海道の駅の開業・改称・廃止を、1950〜2025年の年単位で表示する地図です。廃止された駅も薄い点で残します。

- 年スライダーと再生／一時停止（キーボードの ← → とスペースでも操作可）
- 営業中の駅は明るい点、廃止された駅は薄い点。その年に開業した駅は白、その年に廃止された駅は赤系の点
- 点を押すと、駅名の変遷、路線、事業者、元データの設置期間を表示
- 廃止駅（Closed stations）・路線（Lines）の表示切替、全道・十勝・札幌・函館への移動
- 2025年の表示は、データ基準時点（2025年末）の状態
- 画面の文言は英語。駅名・路線名・事業者名は元データのまま日本語

営業中の駅数（物理的な駅単位）は 1950年 1,101 → 1964年 1,195（最多）→ 1990年 625 → 2025年 422。

## データ処理の規則

### 北海道の抽出

元データには都道府県の属性がないため、位置で判定しています。
大きな矩形では、下北半島の下北交通大畑線（大畑 41.40°N）や、津軽半島の津軽線・海峡線の本州側の駅が混入します。
そこで、津軽海峡の中央付近を南端とする多角形（`HOKKAIDO_POLYGON`）で抽出しました。

- 北海道側で最も南の駅：渡島大沢（松前線）41.42°N
- 除外した本州側の駅の例：大畑、竜飛海底、三厩、中小国（海峡線のレコードを含む）
- 吉岡海底（海峡線）は北海道側として含む

抽出結果は、全国 23,864 レコードのうち 2,074 レコード（すべて Point）、路線は 241 区間です。
路線は一点でも北海道内に入る区間を残しているため、海峡線は青函トンネルの本州側まで描かれます。

対象は元データと同じく旅客鉄道・軌道の駅です。貨物駅、信号場、操車場は含みません。
簡易軌道・路面電車の停留場も含みます。

### 年の扱い

| 属性 | 意味 | 扱い |
|---|---|---|
| N05_005b | そのレコードの設置期間の開始年 | 表示開始年 |
| N05_005e | 設置期間の終了年＝**変更・廃止年の前年** | その年までは存在したとみなす。廃止年は「終了年＋1」 |
| 9999 | データ基準時点で存続 | 2025年まで営業。「9999年」とは表示しない |
| 999 | 不明 | 下記の規則で補う。補えないものは「期間不明」として別表示 |
| N05_004 | 供用開始年 | 詳細欄に表示するのみ。1950年以前の変遷は再現しない |

表示年 Y にレコードが有効なのは `開始年 <= Y <= 終了年` のとき。

例：幸福駅（広尾線）は N05_005b=1956、N05_005e=1986。1956〜1986年は営業中、1987年からは廃止駅として表示します。詳細欄の表記は「Last year in data: 1986 → closed 1987」です。

999（不明）の補い方：

1. 開始年が不明 → 同じ関係IDの前のレコードの終了年＋1。無ければ供用開始年（1950年より後の場合）。それも無ければ 1950年から表示
2. 終了年が不明 → 同じ関係IDの次のレコードの開始年−1。無ければ終了年不明とし、営業中にも廃止にも数えず、輪郭だけの点で示す（主に「線路班」と付く仮乗降場、函館・旭川の路面電車の停留場など）

補った内容は、駅の詳細欄に英語の注記で表示します。

### 物理的な駅への統合

元データのレコードは路線ごと・期間ごとに分かれています。同じ駅でも、路線が違えば別レコード・別の関係IDです。
地図では次の規則でまとめ、一つの点として表示しています。

1. 関係ID（N05_006）が同じレコードは同じ駅（改称・移管・移転を含む）
2. 距離 30m 以内のレコードは、駅名にかかわらず同じ駅
3. 距離 300m 以内で駅名が同じ、かつ事業者区分が同じなら同じ駅（日本国有鉄道と JR北海道は同じ区分）
4. ただし 2・3 は、期間が重なるか 1年以内で接しているものに限る

4 は、路面電車の停留場と、何年も後に同じ場所にできた地下鉄駅（例：拓銀前と地下鉄大通）を別の駅として扱うためです。
3 の事業者区分は、十勝鉄道の帯広駅のように国鉄駅のそばにあった別会社の駅を、国鉄・JRの駅と分けるためです。

結果は 2,074 レコード → 1,572 駅です。画面の駅数は物理的な駅単位で数えています。

駅の状態は、まとめたレコードのいずれかがその年に有効なら「営業中」です。
帯広駅では、士幌線・広尾線のレコードが1986年で終わっても根室線のレコードが続くため、営業中のままです。
改称（狩太→ニセコ）や会社の移管（江差線→道南いさりび鉄道）も、レコードが続いていれば廃止として扱いません。
すべてのレコードが終わった駅だけを「廃止」とし、その廃止年を「最後の終了年＋1」とします。

### 移転・改称の表し方

- 点の位置と表示名は、その年に有効なレコードのものを使う。移転（例：苗穂 2018年、糠平 1955年）は点の位置が、改称は表示名が、該当する年で切り替わる
- 廃止後は、最後のレコードの位置と名前で薄い点を表示する
- 詳細欄には、まとめたすべてのレコード（駅名・路線・事業者・元の設置期間・供用開始年）を並べる

### 確認対象（data/review.csv）

規則だけでは判断できないものを書き出しています（44件）。

- 統合後の点が 500m 以上離れている（移転。上野幌、夕張、糠平、東風連→名寄高校 など）
- 同じ駅のレコードの間に空白年がある（原生花園、札幌市電の一部停留場など）。空白の年は廃止駅として表示される
- 同名で 1km 以内にあるが別駅として扱った（十勝鉄道の帯広、根室拓殖鉄道の根室、地下鉄と国鉄の琴似 など）

## 既知の限界

- 年単位で、日付単位の変遷は扱わない。年の途中で廃止された駅も、その年は営業中として表示する
- 1950年より前の変遷、2026年以降の変化は含まない
- 「駅位置推定」の注記がある 274 レコードは、元データでも位置が推定
- 物理的な駅の統合は上記の規則で機械的に行っており、史実との照合はしていない
- 簡易軌道や路面電車の停留場も駅として数えている
